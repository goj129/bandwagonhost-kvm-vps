## 常见问题

**这套 VPS 需要自己装系统吗？** KiwiVM 面板提供一键重装，系统模板覆盖 AlmaLinux、RockyLinux、CentOS、Debian、Ubuntu、Fedora 等 20 多种，也支持自行挂载 ISO 安装。近期官方还上线了 Debian 13 和 Ubuntu 26.04 模板。

**机器性能怎么样？** 官方近年陆续在洛杉矶 DC9、香港 HK3/HK8 和纽约机房换装 AMD EPYC 平台加 NVMe RAID-10 存储，但不同机房、不同批次的硬件存在差异，下单后以 KiwiVM 面板里看到的实际配置为准。

**支持 VPN/代理用途吗？** 官方明确所有 VPS 支持 PPP 和 tun/tap，拥有完整 root 权限；但服务条款禁止垃圾邮件、攻击行为、挖矿等用途，违反会被封号。
